📋 How It Works

  1. Your request is submitted to the VRF smart contract on Stellar
  2. The oracle fetches a drand beacon for the required round
  3. Oracle generates a BLS12-381 VRF proof using its secret key
  4. The contract verifies the proof with a pairing check on-chain
  5. The verified random output (beta) is stored permanently
  6. Anyone can verify the result is unbiased and unpredictable
