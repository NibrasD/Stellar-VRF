ðŸ”® What is Stellar VRF?

Stellar VRF is a Verifiable Random Function oracle for the Stellar/Soroban blockchain. It generates cryptographically provable random numbers using BLS12-381 cryptography and the drand distributed randomness beacon.

Any dApp can request on-chain randomness by calling the VRF smart contract. The oracle fulfills the request with a BLS proof that is verified on-chain â€” ensuring the result is tamper-proof, unbiased, and publicly auditable.

The fastest way to integrate. Install the SDK and call the contract with a few lines of code. Works in Node.js and browser environments.

1. Install

Terminal

2. Request Randomness

JavaScript / TypeScript 
import { VrfClient, Networks } from "@stellar-vrf/sdk";
import { Keypair } from "@stellar/stellar-sdk";

const client = new VrfClient({
  contractId: "CCN75KEGLETGRTVJJDMXB2ZRQD6PC2S56VUOEKVLQPVEIJYGSOV55G57",
  rpcUrl:     "https://mainnet.sorobanrpc.com",
  networkPassphrase: Networks.MAINNET,
  keypair:    Keypair.fromSecret("S..."),  // signs locally, never sent
});

// Context binds the randomness to your specific use case
const context = new TextEncoder().encode("audit-round-42");
const requestId = await client.request(context);
console.log("Request ID:", requestId);

3. Wait for Fulfillment & Get Result

JavaScript / TypeScript 
// The oracle typically fulfills within 10â€“30 seconds
const proof = await client.waitForFulfillment(requestId, 120_000);
console.log("Beta output:", Buffer.from(proof.betaOutput).toString("hex"));

// Derive a random number in an inclusive range [1, 1000]
const result = await client.deriveRandomInRange(requestId, 1n, 1000n);
console.log("Random number:", result);

ðŸ¦€ Option B â€” Soroban Consumer Contract (Rust)

For fully on-chain integration, your Soroban contract can request randomness and receive the result via a callback. This is the most secure approach â€” everything happens on-chain.

1. Request with Callback

Your contract calls request_with_callback() on the VRF contract. When the oracle fulfills the request, the VRF contract calls your on_vrf() function automatically.

Rust (Soroban) 
pub fn request_sample(env: Env, requester: Address, range_max: u64) -> u64 {
    requester.require_auth();

    let vrf_contract: Address = env.storage().instance()
        .get(&ConsumerKey::VrfContract).unwrap();

    let context = Bytes::from_slice(&env, &range_max.to_be_bytes());
    let self_addr = env.current_contract_address();

    // The VRF contract will call on_vrf() when randomness is ready
    let sample_id: u64 = env.invoke_contract(
        &vrf_contract,
        &Symbol::new(&env, "request_with_callback"),
        vec![&env,
            context.into_val(&env),
            self_addr.clone().into_val(&env),
            self_addr.into_val(&env),
            Symbol::new(&env, "on_vrf").into_val(&env),
        ],
    );

    // Track the pending request
    env.storage().persistent()
        .set(&ConsumerKey::PendingSample(sample_id), &range_max);
    sample_id
}

2. Receive the Callback

âš ï¸ Important: The VRF contract is the caller of on_vrf(), not the user or the oracle. You must call vrf_contract.require_auth() to verify the caller.

Rust (Soroban) 
pub fn on_vrf(env: Env, sample_id: u64, beta_output: BytesN<32>, _alpha_seed: BytesN<32>) {
    // CRITICAL: Only the trusted VRF contract may call this
    let vrf_contract: Address = env.storage().instance()
        .get(&ConsumerKey::VrfContract).unwrap();
    vrf_contract.require_auth();

    // Idempotency: reject duplicate callbacks
    if env.storage().persistent().has(&ConsumerKey::SampleResult(sample_id)) {
        return;
    }

    // Validate this is a request we initiated
    let range_max: u64 = env.storage().persistent()
        .get(&ConsumerKey::PendingSample(sample_id))
        .unwrap_or_else(|| panic!("unknown sample_id"));

    // Derive a random value in [0, range_max)
    let arr = beta_output.to_array();
    let raw = u64::from_be_bytes(arr[0..8].try_into().unwrap());
    let sample = raw % range_max;

    env.storage().persistent()
        .set(&ConsumerKey::SampleResult(sample_id), &sample);
}

ðŸŒ Option C â€” Direct Browser Integration

If you prefer not to use the SDK package, you can call the VRF contract directly using the Stellar SDK from a CDN. This is exactly how the Playground works.

HTML 
<script src="https://cdn.jsdelivr.net/npm/@stellar/stellar-sdk@17.0.1/dist/stellar-sdk.min.js"></script>
<script>
  const { Keypair, TransactionBuilder, Operation,
          nativeToScVal, scValToNative, rpc } = StellarSdk;

  const CONTRACT = "CCN75KEGLETGRTVJJDMXB2ZRQD6PC2S56VUOEKVLQPVEIJYGSOV55G57";
  const server   = new rpc.Server("https://mainnet.sorobanrpc.com");
  const keypair  = Keypair.fromSecret("S...");

  // Build and submit the request() transaction
  const contextBytes = new TextEncoder().encode("my-context");
  const account = await server.getAccount(keypair.publicKey());
  const tx = new TransactionBuilder(account, {
    fee: "2000000",
    networkPassphrase: "Public Global Stellar Network ; September 2015",
  }).addOperation(Operation.invokeContractFunction({
    contract: CONTRACT,
    function: "request",
    args: [
      nativeToScVal(contextBytes, { type: "bytes" }),
      nativeToScVal(keypair.publicKey(), { type: "address" }),
    ],
  })).setTimeout(120).build();

  const sim = await server.simulateTransaction(tx);
  const prepared = rpc.assembleTransaction(tx, sim).build();
  prepared.sign(keypair);
  await server.sendTransaction(prepared);
</script>
