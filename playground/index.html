🔢 Verifiable Random Number

Generates a publicly verifiable random number on-chain using a BLS12-381 VRF and drand. Useful for fair selection, audit sampling or NFT trait assignment. The proof is checked on-chain against the registered oracle and drand keys; the oracle operator remains a trusted party (it can rotate those keys; see the threat model ↗).

✅ Verify On-Chain

Check whether a request has been fulfilled and its BLS12-381 pairing proof verified on-chain. The proof stays in contract storage until cleanup_proof() removes it or Soroban storage TTL archives it; the fulfill transaction remains the permanent record. The Fulfilled flag and beta survive cleanup_proof().

🧮 Client-side Range Derivation

Reproduces the contract's derive_random_in_range(request_id, max) (v2: sha256("VREP_DERIVE_V2" ‖ 0x02 ‖ request_id ‖ max ‖ beta) with exact two-candidate rejection sampling) entirely in your browser. The range is inclusive: result = Min + derive_random_in_range(id, Max − Min + 1). Use Derive for a purely offline result, or Derive & compare with on-chain to load the beta of a fulfilled request from the contract and check that the browser and derive_random_in_range() return the same value.
